## 5. 样本

- `examples/sample-paper.tex`：自制 3 页 A4 样本，包含摘要、正文、公式、表格、引用与较长阅读页，无版权问题。
- `examples/sample-paper.pdf`：由 `tools/build-sample-pdf.sh` 生成。
- `examples/sample-paper.pdf` 约 124 KiB；每次重新生成时 PDF 文件字节可能因生成器元数据变化而不同，因此 `.pano` 绑定应以当前生成文件的 SHA-256 为准。

## 6. 五项阶段判断

1. **Qt PDF 是否继续采用**：继续。Qt 6.12 SDK 的 QtPdf 在 Linux 上加载、渲染、选择、多线程页面渲染均可用；前提是 QtPdf 与 Widgets 来自同一套 Qt 安装。若目标机器只能使用系统 Qt 6.12.1 而没有匹配的 QtPdf，会阻塞，需要在构建文档中明确 SDK 要求。
2. **自主控件架构是否合适**：合适。`QAbstractScrollArea` + `PageLayout` + `PdfView` 把页面几何、滚动、命中、绘制集中在少数边界内，后续加入双页、缩略图或书架时不需要推翻阅读控件。建议继续保留“页面坐标 pt”和“视图变换”分离。
3. **坐标及文字定位契约是否可冻结**：几何契约可以暂冻结：页面 0-based、pt、未旋转左上原点、X 右 Y 下；保存/重开、旋转/缩放往返与哈希保护已验证。文字选择契约暂不冻结：跨行、多栏、旋转页面和恢复索引的真实行为还没有足够人工样本，下一阶段应先补齐这些观察，再决定是否把字符索引作为长期稳定字段。
4. **混合与对象编辑方案是否可靠**：方向可靠。普通/正片叠底通过 `QPainter` 合成，荧光笔用离屏蒙版一次合成，避免同一笔内部重复加深；对象级命令和笔记恢复已通过探针。但 V08/V09 的视觉与重叠命中仍需人工验收，暂不宣称已达到正式基线。
5. **Markdown/公式和 JSON 存储是否适合作为正式基线**：适合作为 Phase 0 基线。JSON 是明文、原子写入、按创建顺序保存，SHA-256 绑定能阻止静默错绑；Markdown 解析和本地公式渲染不依赖网络。公式仅覆盖最小 TeX 子集，正式阶段需要明确支持范围和降级策略，或评估替换渲染器。

## 7. 已知局限与风险

- 没有 OCR；扫描 PDF 只能做几何标注，不能做文字选择/文字标注。
- 文字选择限单页；跨页选择、跨页高亮未实现。
- 公式渲染器为自研最小子集，不支持矩阵、颜色、复杂对齐、`\begin{aligned}` 等；渲染失败时目前以原始文本/空图降级。
- 区域截图截取当前视图像素，缩放和高 DPI 下清晰度有限；应在正式阶段改成按页面坐标和渲染倍率截取。
- 页面缓存只缓存原始页面图像，标注不进入缓存；这在当前规模下正确，但大量标注时的重绘成本尚未测。
- 未实现书架、多文档、全文搜索、PDF 导出、安装包和自动更新。
- Windows 未构建；高 DPI、触控板、输入法、超大 PDF 未验收。
