## 1. 背景与开发目标

Phase 1 已建立正式工程、书库、书架、数据格式、文档会话及多文档管理；Phase 1.1 完成了书库和阅读工作区的界面重构、图标、导航、独立工具预设、快速属性栏及保存机制的主要改进。

本轮实际使用反馈表明：缩略图、标注定位、阅读位置恢复、颜色切换及铅笔/荧光笔独立预设基本正常，应保持这些能力；仍有字体实时刷新不完整、文字高亮断裂、画笔结束时异常向前滚动、线宽必须回车才生效、笔迹无法正常缩放等问题。上一轮静态检查还发现永久删除、设置取消以及延迟属性提交方面的风险。

本阶段的目标不是继续扩展书库或全面重构阅读器，而是围绕三个设计目标进行一次集中完善：

1. **标注对象化**：直线、矩形、椭圆、铅笔、荧光笔均具备可靠的几何编辑和样式修改能力。
2. **选择统一化**：默认选择工具可以识别标注、可选文字及页面区域，不要求用户频繁切换工具。
3. **操作上下文化**：文字与区域选取完成后提供浮动操作入口；工具预设和已创建对象的属性编辑各自独立。

同时修复明确的底层缺陷及数据安全问题。完成后应能以默认选择模式进行大部分日常阅读与笔记操作，并保留专用标注工具用于连续标注。

## 3. 基础缺陷修复

### 3.1 R01 — 跨平台编译

Windows MSVC 报告 `TextSelectionGeometry.cpp` 中 `M_PI` 未声明，并引发 `angle` 初始化的连带错误。`M_PI` 不是 ISO C++ 标准宏，Linux 下可用不代表 Windows 下可用。

正式工程使用 C++20，应添加 `<numbers>`，将两处 `M_PI` 替换为 `std::numbers::pi`（需要特定类型时使用 `std::numbers::pi_v<T>`）。搜索正式源码中同类非标准数学宏，按实际需要替换。不使用全局 `_USE_MATH_DEFINES` 作为首选修复，不修改归档 Demo。若用户已在最新提交中完成此项，只核查即可。

### 3.2 R02 — 统一路径几何边界

基线 `src/annotation/Annotation.cpp:96–109` 使用零尺寸 `QRectF` 的合并运算获取路径边界；`PdfView::updateDraw()` 和 JSON 反序列化也存在类似实现。Qt 对 null rectangle 的合并有特殊处理，不能用其代替点集极值计算。结果可能退化为单个点，导致控制点重合、变形提前返回以及定位失败。

建立统一的几何计算函数（可置于 annotation/ 中的几何辅助模块），使用点集的 `xmin/xmax/ymin/ymax` 计算路径边界。空路径须有明确的无效状态，不得将空矩形与有效零宽/零高几何混为一谈。调用者应能区分：无几何、单点、水平线、竖直线、一般二维路径。

建议区分三类边界：

| 边界 | 作用 |
| --- | --- |
| 几何边界 | 路径中心线或图形自身的 point 坐标范围，用于几何变换 |
| 绘制边界 | 考虑线宽、端帽、连接方式等实际影响区域，用于绘制裁剪、定位 |
| 交互边界 | 考虑固定屏幕像素的命中容差和控制点，用于鼠标交互 |

例如水平荧光笔的中心线高度可以为零，但实际绘制边界具有正常高度。命中检测应使用真实路径和合理容差，不得将整块外接矩形内部都当作笔迹（空心图形也应按轮廓命中）。对于有填充的图形，内部可命中。

实现示意：

```cpp
// 非空且坐标有效时返回几何边界；调用者自行区分退化与无效。
QRectF pathBounds(const QVector<QPointF>& points)
{
    if (points.isEmpty()) return {};
    qreal xmin = points.first().x(), xmax = xmin;
    qreal ymin = points.first().y(), ymax = ymin;
    for (const auto& p : points) {
        xmin = std::min(xmin, p.x()); xmax = std::max(xmax, p.x());
        ymin = std::min(ymin, p.y()); ymax = std::max(ymax, p.y());
    }
    return QRectF(QPointF(xmin, ymin), QPointF(xmax, ymax));
}
```

统一检查创建预览、加载 JSON、移动、缩放、控制点、命中、渲染、定位等入口。路径点是权威几何，不再持久化重复的包围盒。旧文件中的路径点仍可直接使用，无需为修复包围盒而重写数据。

### 3.3 R03 — 标注选择与定位分离

基线 `PdfView::finishDraw()` → `addAnnotation(..., true)` → `selectAnnotation()` → `ReaderWorkspace::onSelectionChanged()` 会触发 `revealAnnotation()`。`annotationPageRegion()` 又在包围盒为空时回退到 `p1`；自由路径并不以 `p1` 为几何依据，可能定位到页面原点附近。这是当前异常跳转的重要代码线索。

明确行为边界：

| 操作 | 是否主动滚动 PDF |
| --- | --- |
| 新建标注、点击页面标注、修改样式 | 否 |
| 移动/缩放对象、撤销重做 | 否（保留视图位置） |
| 更新列表选中项、右侧面板联动 | 否 |
| 用户点击左侧标注/笔记导航项 | 是 |
| 用户执行定位原文、点击目录或缩略图 | 是 |

`selectAnnotation(id)` 只修改选中对象及界面联动；`revealAnnotation(id)` 为显式导航入口。删除 `onSelectionChanged()` 中无条件定位的逻辑。列表程序化刷新不得再次触发导航；使用信号阻断或明确的操作来源区分用户选择与程序同步。

定位使用类型对应的权威几何：路径使用真实路径边界（含笔画）或有效路径点，直线使用端点及线宽，文字使用整理后的选区，定位笔记使用自身坐标。仅在有效几何确实为点时使用点定位；无效数据应报告或跳过，不默认定位到 `(0,0)`。

保持现有正常工作的页内锚点、目录导航及阅读状态恢复机制。缩放、旋转、面板布局变化时仍使用统一的 PageTransform，不新增独立的坐标转换链路。

## 4. 数据安全与设置修复

### 4.1 R04 — 永久删除失败恢复

上一轮已改善删除前保存并关闭文档会话的行为，但基线 `LibraryManager::deletePermanently()`（约 363–395 行）仍先删除实际目录，再写书库/书架索引，且底层缺少明确的回收站状态校验。

本轮要求：

1. 仅允许永久删除已经进入回收站的书籍，底层与界面均须校验。若存在打开的会话，先提交待编辑内容、保存并关闭，失败时终止。
2. 确认目标目录属于当前书库的受控书籍目录，禁止路径穿越、符号链接逃逸及对外部映射 PDF 的删除。拷贝模式只处理书库内部受控副本。
3. 使用同一书库文件系统内的临时隔离目录，例如 `.pending-delete/<operation-id>/`，先记录必要的操作信息及索引快照，再移动书籍目录。移动失败不得转为未经保护的直接删除。
4. 使用现有原子写入机制更新 `library.json` 与 `shelves.json`，并按一致性要求清理阅读状态/历史关联。多文件写入不是单文件原子操作，应保留必要的恢复记录。
5. 索引更新全部成功后，标记操作为已提交，再执行不可逆清理。清理失败时保留隔离数据和记录，提示用户后续重试，不恢复已提交的索引关系。
6. 提交前任一环节失败，恢复原目录、已更新的索引及内存模型。若恢复失败，保留隔离数据、日志和恢复记录，停止相关写入并明确提示。不得报告成功或静默丢弃数据。
7. 下次启动时检查未完成操作：根据操作阶段和索引实际状态执行安全恢复或提示人工处理。不得仅凭隔离目录存在便自动清空其中数据。检测到外部并发修改时避免盲目覆盖。

无需引入数据库或通用事务框架；可针对该操作实现轻量恢复记录。清空回收站时逐本执行同一流程，明确报告失败项目。删除书架不删除其中书籍的原有语义保持不变。

同时检查上一轮已有的笔记编辑 ID 绑定、自动保存与外部文件修改检测；新增属性操作应在保存、关闭、切换标签页及删除前按一致规则完成或取消，不能绕过保护。

### 4.2 R05 — 统一外观更新

实测：设置字号时只有菜单栏即时更新，其他控件重启或切换主题后才生效。基线 `SettingsDialog::applyFont()` 主要调用 `QApplication::setFont()`，而 `ThemeManager::apply()` 还应用全局 QSS。具体平台传播路径需通过运行验证，不能只认定为单一 Qt 缺陷。

要求建立一个统一的外观应用入口（例如 `ThemeManager::applyAppearance(theme, fontSettings)`）：

- 主题与字号仍是独立配置；使用统一的外观更新顺序，处理应用字体、QPalette、QSS 及必要的 repolish/布局刷新。
- 普通控件继承基础字号；显式设置字号的标题、辅助文字、自绘控件及笔记预览以统一基础字号计算相对值。不得因创建时固定字号而阻断后续更新。
- 检查工具按钮、标签页、菜单、树与列表、列表 delegate/sizeHint、设置窗口、详情面板、笔记编辑/预览及自定义绘制。必要时更新图标尺寸、行高、间距和布局尺寸，避免文字截断。
- 更新所有已打开的工作区，不依赖重启、切换其他主题或重新创建文档会话。维持 PDF 自身颜色、已保存标注样式及阅读缩放；适宽布局如因窗口有效尺寸改变而重算，需尽量维持页内阅读锚点。

建议实际检查 10/12/14 pt、浅色与深色主题、较小窗口及可获得的高 DPI 环境。默认字号维持现行 11 pt，不借此重新设计整套主题。

### 4.3 R08 — 设置窗口语义

主题、字体允许实时预览；其他配置（默认导入方式、自动保存参数、工具预设等）在确定或应用时提交，避免预览外观顺便修改不相关设置。

- 打开窗口时初始化控件，使用 `QSignalBlocker` 或加载保护，避免写入配置。
- “应用”提交当前有效设置并更新取消恢复基线；“确定”提交并关闭；“取消”恢复自上次成功应用以来未提交的更改及实时外观预览。
- 书库切换仍使用独立的保存、关闭、加载和锁处理流程，不能作为普通实时预览的一部分。
- 配置保存失败应提示，不把未成功持久化的状态当作新基线。重点核查上一轮未恢复默认导入方式的问题。

## 5. R06 — 文字选区几何处理

### 5.1 问题和处理原则

本轮截图显示：两端对齐英文段落中，较宽的词间距以及某些字符附近仍存在高亮断裂。基线 `TextSelectionGeometry::mergeLineBands()` 使用 `max(1.2 pt, localHeight * 0.55)` 作为合并上限，容易将本应连续的文字误分为多个区段；`previousRight = glyph.box.right()` 在重叠或包含的片段中也可能使右边界回退。

不能单纯将全局间距阈值增大到某个固定值，因为这会增加双栏、表格和公式的误合并风险。应优先使用可靠的文字连续性，结合空间特征判断。

### 5.2 建议算法

1. 获取页内原始文字选区、文字起止索引、原文、多边形。检查坐标、文字方向及 API 提供的信息是否可靠。
2. 根据方向、垂直重叠、行高、基线或局部行带进行分组；不能仅按全页 Y 值或第一个字符作为唯一行锚点。兼顾粗体、标点、大小字体和上下标；特殊排版无法判断时保守回退。
3. 在同行内确定连续区段。若能确认字符/词片段与文字索引的对应关系，且中间仅有同一行正常空白，允许适度跨越两端对齐造成的较大词间距。必须同时检查栏间空白、表格边界、不连续片段等空间证据。
4. 不能假定 Qt 返回的每个多边形与一个字符一一对应。若需要，可通过 `getSelectionAtIndex()` 按实际 Qt API 验证局部索引与几何关系；避免每次绘制逐字符调用引擎。对于无法获得可靠对应关系的文档，采用行内局部统计（如典型字高、词间距）及保守上限处理。
5. 合并过程中使用当前连续区段的最右边界（或方向对应的投影极值），避免 `previousRight` 回退。不要用整段文字的单个外接矩形；第一行、末行的部分选择必须保留真实边界。
6. 高亮、下划线、删除线、临时文字选区显示、命中检测及定位使用同一份整理后的行区段。下划线和删除线的位置按各行带计算，不连跨栏间距。

建议为相同选区缓存显示几何；缓存属于运行时派生数据，文字范围、PDF 身份或算法输入改变时失效。不为普通滚动/缩放重复请求文字索引或重新进行昂贵聚类。保持页面 point 坐标。

### 5.3 原始几何与兼容

基线 `PdfView::createTextAnnotation()` 约 1735 行已将 `normalize(selection.bounds())` 写入标注，而渲染时又进行整理，与原设计的原始几何存储原则存在差异。

本轮新建文字标注应保存原始有效多边形、索引及原文；整理后的几何只用于显示和交互，不重复持久化。旧数据可能已经保存合并后的多边形，不能将其视为必然的原始几何。若 PDF 哈希一致、索引语义及范围有效，可尝试重新获取选区并核验原文，仅作为运行时改进；核验失败时保留旧几何正常显示，不覆盖文件、不丢弃标注。需要明确记录新旧 `polygons` 的兼容读取规则。

主要验收样本：用户反馈的两端对齐英文段落、中文段落、跨行部分选取、双栏论文、粗体标点及上下标；无法可靠处理的竖排/特殊方向文字应保留原选区，不应错误覆盖其他区域。

## 6. R07、F01 — 快速属性与图形线型

### 6.1 线宽的即时提交

基线 `ReaderWorkspace.cpp:392–400` 使用 `setKeyboardTracking(false)` 及 `editingFinished`，造成输入线宽后未结束编辑时预设不更新。改为有效数值变化时生效：监听 `valueChanged`，允许键盘输入、步进按钮和常用值选择，不能要求回车才能应用。对暂时无效的输入不提交；失去焦点或开始绘制时应处理最后的有效值。

可采用可编辑下拉框或保留 spinbox 并增加常用值入口。建议常用值：0.5、1、1.5、2、3、5、8、12、16 pt，允许手动输入；不要因更换控件而缩窄既有合法数据范围。常用值及图标可根据视觉效果微调。

### 6.2 延迟提交目标绑定

当前约 140 ms 的防抖样式提交可能在切换工具或对象后读取新的当前状态。应区分以下两种目标：

- 绘制模式：`ToolId` 对应的独立本机预设，仅影响后续新建标注。
- 对象选择模式：`BookId/SessionId + AnnotationId` 对应的已有标注，修改应进入撤销历史，不影响任何工具预设。

延迟操作必须绑定发起时的目标和有效样式快照，而不是定时器触发时重新读取当前选中对象。切换对象、工具、文档、保存、关闭或删除前，先完成有效待提交操作；目标失效时安全取消。程序化刷新控件不能触发反向属性写入。可采用拖动期间实时预览、完成后提交一条命令，或合并相同对象的连续撤销命令。不能为每个数值变化创建大量命令。

工具预设应在所有文档工作区保持一致（或在激活时读取统一配置），但各会话的当前工具及选中对象保持独立。新建标注取创建时有效预设，不受旧的对象选中状态影响。

### 6.3 图形线型（F01）

为直线、矩形和椭圆增加描边线型，复用 Qt `QPen` 标准线型，不自研虚线算法。

| 数据值 | 中文名称 | Qt 映射 |
| --- | --- | --- |
| `solid` | 实线（默认） | `Qt::SolidLine` |
| `dash` | 虚线 | `Qt::DashLine` |
| `dot` | 点线 | `Qt::DotLine` |
| `dash_dot` | 点划线 | `Qt::DashDotLine` |
| `dash_dot_dot` | 双点划线 | `Qt::DashDotDotLine` |

快速属性栏增加带线型预览的下拉选择；对应工具预设和选中图形均支持修改。右侧详情若提供相同属性，应绑定同一编辑入口。线型只作用于描边，不改变填充、线宽、透明度或混合模式。铅笔、荧光笔和文字类标注暂保持原有连续绘制方式。

普通与正片叠底两种绘制路径都应使用正确线型，预览和正式渲染保持一致。命中检测可沿完整几何轮廓（包括虚线间隙）提供易用容差，不需要逐个虚线片段进行像素命中。

样式示例（沿用当前 ARGB 颜色字符串格式）：

```json
{
  "stroke_color": "#FFD94F4F",
  "stroke_width_pt": 1.5,
  "line_style": "dash",
  "fill_color": null,
  "opacity": 1.0,
  "blend_mode": "normal"
}
```

旧文件缺少 `line_style` 时按实线加载。工具预设的序列化、加载、恢复出厂值和撤销/重做同步覆盖该属性。格式版本策略见第 10 节。

## 7. F02、F03 — 几何约束及对象编辑

### 7.1 Shift 绘制约束（F02）

统一 Shift 作为几何约束键，不另设正方形、正圆等标注类型。

| 工具/操作 | 普通操作 | Shift 约束 |
| --- | --- | --- |
| 直线 | 任意方向 | 水平、竖直、45° 方向吸附 |
| 矩形 | 任意宽高比 | 正方形 |
| 椭圆 | 任意宽高比 | 正圆 |
| 铅笔、荧光笔 | 自由路径 | 起点至当前点的直线式笔迹，方向吸附 |
| 图形/自由路径角点缩放 | 横纵独立变形 | 保持原始宽高比 |

矩形、椭圆以鼠标按下点作为固定角点，正确处理四个拖动象限。可采用 `side = max(abs(dx), abs(dy))`，再按拖动方向计算终点；接近页面边界时限制共同边长，而非分别裁剪 X/Y 导致正方形变形。方向吸附基于操作时的视觉方向，与已有页面旋转变换保持一致；吸附后的点仍须转换为原始页面坐标存储。

Shift 在拖动期间按下或松开时预览应实时更新，即使鼠标暂时静止也应正确处理；释放鼠标时最终几何与预览一致。对于自由笔迹，临时约束状态不应破坏此前采集的原始拖动轨迹：按住 Shift 使用两端点预览，松开后恢复合理的自由路径。保留连续标注及 Esc 取消行为。

### 7.2 控制点设计（F03）

基线已在 `Annotation::isResizable()` 中允许路径缩放，但 `setBounds()` 遇到退化边界会提前返回。R02 修复几何边界后仍须处理真实水平、竖直路径及线段，不允许简单地给分母加极小常量制造异常缩放。

```
直线/直线式笔迹：                 矩形、椭圆、一般路径：

 ●----------------●             □-----------□-----------□
 起点             终点           |                       |
                                 □       图形/笔迹       □
                                 |                       |
                                 □-----------□-----------□
```

| 对象类型 | 交互控制 |
| --- | --- |
| 直线 | 独立起点、终点；拖动线段整体移动；端点移动支持 Shift 方向约束 |
| 矩形、椭圆 | 八个控制点；边控制单轴尺寸、角控制双轴尺寸，Shift 角点保持宽高比 |
| 一般铅笔/荧光笔路径 | 八个控制点；将原始路径点整体映射到新几何边界，支持横纵及等比例缩放 |
| 直线式铅笔/荧光笔 | 两个端点，可修改长度、方向、位置；可用已有两点路径表达，无需新增类型 |
| 退化或近退化的自由路径 | 使用适当的单轴/端点编辑及可见交互边界，避免除零、无效控制点及异常变形 |
| 定位笔记 | 允许移动定位点，不提供无意义的缩放 |
| 文字类标注 | 仍以文本选区为权威几何，不提供任意移动/缩放；保留属性与笔记编辑 |

一般路径采用从拖动开始时几何到当前目标几何的映射，不累计上次拖动产生的浮点误差。例如非退化轴：`x' = newLeft + (x - oldLeft) * newWidth / oldWidth`；对退化轴使用明确的约束或平移策略，不做除零计算。两端点路径直接编辑对应点。笔迹尺寸与描边线宽分离：默认缩放路径坐标，不改变笔宽、颜色、透明度和混合方式。

控制点大小与命中容差采用固定的逻辑屏幕尺寸，位置根据统一页面变换绘制；高 DPI 由 Qt 正常处理。移动控制点时避免对象突然翻转或跳跃，可在本阶段限制穿越对侧边界；保持最小有效尺寸和页面边界约束。缩放后的对象不得产生 NaN/Inf 或异常坐标。可编辑边界与包含线宽的定位边界不必完全相同。

所有移动、缩放、端点调整共用临时对象机制：鼠标按下记录原对象，拖动显示临时结果，释放后提交一次撤销命令，Esc 取消并恢复。对象 ID、创建时间、笔记、样式保持不变（仅更新修改时间及几何）；保存重开后结果一致。本阶段不做自由路径逐采样点编辑、任意控制点插入或复杂旋转手柄。

## 8. F04 — 默认统一选择模式

### 8.1 工具定义

将现有独立的 `Select` 与 `TextSelect` 合并为面向用户的“选择”工具，作为打开阅读器及 Esc 退出专用工具后的默认模式。代码内部可以保留独立的文字、对象、区域交互状态，不等于必须把全部逻辑合并成一个函数。

保留“拖动”工具用于平移页面；保留主动高亮、下划线、删除线，用于连续文字标注；另提供显式“框选”入口，允许在文字或图形上任意开始区域选取。

### 8.2 命中及优先级

在默认选择模式中，悬停时应依据可操作对象显示合理光标；鼠标按下结合修饰键、命中对象及拖动阈值确定本次操作。建议优先级如下：

| 起始条件 | 单击/拖动行为 |
| --- | --- |
| 显式框选模式或 Ctrl 强制框选 | 忽略文字与标注命中，进行区域选择 |
| Alt 强制文字选择（存在可选文字时） | 忽略覆盖在文字上的标注；只选原文 |
| 已选中对象控制点 | 调整几何尺寸或端点 |
| 已有可移动图形/笔迹 | 单击选中，超过拖动阈值后移动 |
| 已有文字标注 | 单击选中对象，拖动时尝试选择其下原文 |
| 可选文字附近 | 拖动选择文字，不创建标注 |
| 页面内非文字区域 | 拖动矩形区域；单击仅取消选择 |
| 页面外空白 | 取消选择，不创建标注 |

上述 Ctrl/Alt 是建议初始映射；Linux 桌面可能拦截 Alt+鼠标拖动，应在目标平台验证并在必要时提供替代修饰键，至少保证显式框选入口及明确的强制文字选取方式可用。实际映射须更新快捷键说明，不允许无提示冲突。

有多个标注重叠时，默认选择绘制层级最靠前且真实命中的对象。空心图形内部不能无条件拦截下方文字。文字附近的判断应采用 Qt PDF 可用的文字命中/字符索引能力并核验实际文字几何，不能仅凭页面包含文字就阻断框选。对于隐藏 OCR 文本层，也应以实际可用文字几何为依据；不开发 OCR。

悬停命中只需查询鼠标附近及当前页，避免移动鼠标时不断提取整页文字或重绘整篇 PDF。单击与拖动使用合理的逻辑像素阈值（建议复用 Qt 拖动距离）；一旦开始实际拖动，锁定交互类型直至释放或取消，不因经过文字、笔迹或空白而切换状态。

### 8.3 状态及操作生命周期

```
默认选择 / 专用工具
        |
        v
鼠标悬停（更新光标，不改变持久化对象）
        |
        v
鼠标按下（记录页码、坐标、命中对象、修饰键）
        |
        +-- 单击 --------------------> 选择/取消选择对象
        |
        +-- 达到拖动阈值
              +-- Resize/Move ------> 对象几何预览
              +-- TextSelection ----> 临时文字选区
              +-- RegionSelection --> 临时矩形选区
        |
        v
释放鼠标：提交一次对象编辑，或保留选区并显示相应操作栏
Esc：取消当前操作/临时选区；无待处理操作时返回默认选择
```

同一会话中维护互斥的有效文字选区、区域选区及对象编辑状态。开始新的有效选择时清理前一临时选择和浮动工具栏；对象编辑完成后仅保留合理的选中状态，不主动定位。切换文档、关闭文档、切换工具、删除相关对象时安全清理相应临时状态，不能将选区转移到另一会话。

本阶段文字和区域选择限定在起始页，拖动越过页面边界时裁剪至该页；多页连续选择及批量标注对象框选不在本轮范围。该限制应在界面行为和说明中一致体现。

## 9. F05、F06、F07 — 浮动操作与工具栏设计

### 9.1 文字浮动工具栏（F05）

用户在默认选择模式中完成有效文字选区后自动显示轻量工具栏，不要求再选择文字标注工具或重新拖选。

```
PDF 页面
 ┌──────────────────────────────────────────┐
 │ The equation of motion describes ...     │
 │ [蓝色临时选区：选中文字，可跨同页数行]     │
 │        ┌──────────────────────────────┐  │
 │        │ 高亮 │ 下划线 │ 删除线 │ 复制 │ 笔记 │
 │        └──────────────────────────────┘  │
 └──────────────────────────────────────────┘
```

| 操作 | 行为 |
| --- | --- |
| 高亮 | 用文字高亮工具当前独立预设创建标注 |
| 下划线、删除线 | 使用各自预设创建对应文字标注 |
| 复制 | 将原文复制到系统剪贴板，不写标注文件 |
| 笔记 | 基于选中文字创建有文字锚点的标注并进入附属 Markdown 笔记编辑 |

“笔记”可复用现有文字高亮类型及其预设作为锚点；如选择更轻量的视觉形式，须明确数据表达，不得仅保存无精确原文位置的笔记。优先复用已有类型，避免新增独立笔记实体或完整笔记树。

重构文字标注创建入口，使其显式接受 `selection/pageIndex/type/style`，不再必须通过 `m_tool` 隐式决定类型。主动文字标注和浮动工具栏共享创建、撤销、保存、几何处理及预设系统。主动工具模式仍允许直接完成连续标注，不必每次弹出工具栏；默认选择模式中通过浮动按钮创建后保持默认选择状态。

浮动工具栏使用统一 Lucide 图标、简短文字或 tooltip，随主题与字号变化。仅在选区有效时显示，优先放置在选区末端附近的空白位置，避免遮住主要选择内容；空间不足时移至上方或侧方，并限制在阅读视口内。不得影响 PDF 布局或触发页面滚动。滚动、缩放和旋转时按页内几何重新定位；选区不可见时隐藏，必要时安全取消。点击工具栏不应因焦点转移而提前清除选区；Esc、点击其他位置或切换工具时关闭。执行创建类操作后清除临时选区并更新新标注，执行复制后可保留选区供后续操作。

### 9.2 矩形区域选择（F06）

统一默认模式中的空白区域拖动、显式框选工具及当前笔记编辑器内的区域截图功能。基线 `RegionCaptureOverlay` 主要处理视口像素矩形，`ReaderWorkspace::startRegionCapture()` 要求先存在标注和笔记编辑状态，本轮应将区域选择从该专用流程中解耦。

区域选择运行时数据至少包含所属会话、`pageIndex` 和页面 point 坐标下的矩形。视口矩形只是显示结果，通过 PageTransform 获取，缩放、旋转及滚动后仍能正确定位。框选限制在单页范围内；过小或无效区域不触发操作。选区框是临时 UI，不是持久化标注，除非用户明确执行创建操作。

```
 ┌─────────────────────────────────────────┐
 │ PDF 原文 / 扫描文字 / 图表 / 数学公式      │
 │    ┌ - - - - - - - - - - - - - ┐        │
 │    |       临时矩形选择范围      |        │
 │    └ - - - - - - - - - - - - - ┘        │
 │   [复制图片] [保存图片] [矩形标注]        │
 │   [区域高亮] [添加笔记]                  │
 └─────────────────────────────────────────┘
```

| 操作 | 实现要求 |
| --- | --- |
| 复制图片 | 复制区域图像至剪贴板，不写入书籍资源 |
| 保存图片 | 通过保存对话框输出 PNG（可选支持其他现有格式），不修改源 PDF |
| 矩形标注 | 按区域几何创建矩形，使用矩形工具当前预设 |
| 区域高亮 | 创建填充区域标注，默认黄色半透明正片叠底、无可见边框 |
| 添加笔记 | 创建与区域绑定的标注并进入笔记编辑，可将选区截图写入 assets 并插入 Markdown |

区域高亮与文本高亮不同：它不依赖文字索引，可以用于扫描页或图像。优先复用矩形对象表达填充与混合样式；若当前样式不能表达无边框填充，可增加可选 `stroke_enabled`（旧数据默认 true）或其他明确等效字段，不能以零线宽引入 Qt cosmetic pen 等意外行为。区域高亮采用独立操作预设，不改变普通矩形工具或文字高亮的默认值。具体初始色和透明度可参考文字高亮，但样式仍允许编辑。

区域笔记建议复用区域矩形标注作为锚点，保留完整区域几何、页码及附属 Markdown，不仅保存页码。截图附件写入使用现有 `DocumentSession::writeAsset()` 或等效安全入口，保存相对书籍目录的资源路径。文件写入失败时不得留下不可用的 Markdown 链接；避免重复建标注。若用户取消笔记编辑，空标注的保留/撤销行为与现有笔记工具一致，不能误删既有内容。截图资源与撤销命令的关系采用现有资源保留策略，不立即删除可能仍被撤销历史引用的资源。

#### 截图内容与质量

截图应明确是否包含已有标注。建议普通截图默认包含当前可见的已有标注，但排除临时选区、控制点、浮动工具栏、页面外背景等 UI；在笔记摘录场景可提供“仅原文”选项，或在现有能力限制下记录其为后续项。不得将屏幕上的选择框当作原文内容保存。

本阶段最低要求：可在正常缩放、旋转下正确截取当前选中页内区域，不出现错误裁剪；使用当前页面显示图像时，应明确清晰度受当前渲染分辨率限制。建议抽取独立区域图像生成接口，根据实际实现条件优先从已渲染页面或 Qt PDF 重新渲染得到图像，再按原始 page point 区域及视图旋转裁剪；若实现高分辨率渲染，要限制像素数量、处理 DPR 和内存占用，不阻塞主界面。高分辨率重渲染不作为本阶段必需验收项，但不得以截图 UI 覆盖层作为长期方案。

现有笔记编辑器中的截图入口可继续保留：调用统一区域选择机制并将结果插入原绑定笔记，不另建一个重复标注；退出截图时恢复此前合理的编辑状态。

保持 Phase 1.1 的阅读器工作区两级水平工具栏与三栏布局，不再改造书库整体视觉结构。

```
└──────────────────────────────────────────────────────────────┘
```

以上折行仅为 Markdown 表达方便；实际工具栏应优先保持单行分组，通过分隔线及合理溢出菜单适配较窄窗口。去除独立的“文本选择”主要入口及相关重复 Action；若旧快捷键存在，可映射到默认选择或明确的强制文字选择入口。保留显式框选按钮用于消除自动判断歧义。

二级属性栏显示规则：

| 当前状态 | 属性内容 |
| --- | --- |
| 默认选择、无对象 | 不显示无意义的编辑控件，可保留简洁提示 |
| 选中已有标注 | 显示该对象支持的属性，修改直接作用于该对象 |
| 专用绘制工具 | 显示该工具预设，修改只影响后续新标注 |
| 直线 | 颜色、线型、线宽、透明度、混合模式 |
| 矩形/椭圆 | 描边色、线型、线宽、填充、透明度、混合模式 |
| 铅笔/荧光笔 | 颜色、笔宽、透明度、混合模式 |
| 文字高亮 | 颜色、透明度、混合模式 |
| 下划线/删除线 | 颜色、线宽、透明度及已有支持的混合属性 |
| 框选/拖动 | 不显示与当前操作无关的样式 |
| 橡皮擦/笔记 | 保留现有合理的属性入口，不扩展无关功能 |

二级属性栏与浮动操作栏是不同概念：前者用于调整当前工具或对象样式，后者用于对临时选择执行操作。不得把临时文字/区域选区作为已创建标注写入持久化模型。

菜单、快捷键、工具栏及浮动工具共享实际操作入口；图标继续使用现有 IconManager，不引入新的图标库。删除确定已废弃且无调用的旧 `MainWindow::buildToolBar()` 等代码（先检查引用），避免重复交互实现。

## 10. 数据格式、配置和兼容性

本轮总体保持现有书库结构、标注身份、页内 point 坐标、Markdown 内嵌及资源相对路径。仅为确有需要的新功能增加字段。

| 内容 | 处理 |
| --- | --- |
| 路径边界 | 运行时派生，继续以 `geometry.points` 为权威数据 |
| 直线式笔迹 | 复用已有路径类型及两个端点，无需新标注类型 |
| 图形线型 | 新增 `style.line_style`；旧文件缺省为 `solid` |
| 区域高亮描边 | 如确有需要新增可选 `stroke_enabled`，旧文件缺省保持原有描边 |
| 文字多边形 | 新建存原始几何；已有合并数据兼容读取及保守回退 |
| 区域笔记 | 优先复用现有矩形及内嵌 note，截图进入 `assets/` |
| 临时选区及浮动工具栏 | 不持久化 |
| 工具预设 | 本机 `tools.json` 更新，旧预设字段缺失时使用对应工具默认值 |

关于版本：可选字段保证的是新程序能读取旧数据，不自动保证旧程序重写新数据时不会丢失字段。实施时检查当前版本校验及未知字段保存行为；如果旧程序会在保存时无提示丢失新线型等数据，建议提升对应标注格式版本（例如 1→2），明确 v1 读取及 v2 写入规则，并保证已支持版本之间的迁移可控。`tools.json` 如有类似问题按其自身版本处理。无需提升无关书库或书架格式版本。若确认可在同一版本内安全扩展，需在格式规范中说明理由及旧程序的使用限制。

加载不支持的高版本或无法可靠解释的线型数据时，不能以默认值静默覆盖原文件；应使用现有版本保护机制拒绝写入或明确报告错误。迁移前保留必要备份。优先按需升级实际写入的书籍数据，不在启动时批量重写整个书库。更新 `docs/specification/` 中对应的实际格式规范及示例。

本轮不改变用户已经确认正常的缩略图、阅读状态恢复及文档定位数据格式。除 R03 所需的选择/定位分离外，不进行无关的阅读器缓存或会话大规模重构。

## 11. 建议的模块职责

在现有架构内按职责调整，以下名称仅用于表达边界，不要求创建大量新类或文件。

| 模块 | 本轮职责 |
| --- | --- |
| `annotation/` | 权威几何、路径边界、文字几何整理、线型、渲染及命中、编辑命令 |
| `reader/` | PageTransform、命中分派、临时选择及交互状态、对象绘制与编辑 |
| `app/ReaderWorkspace` | 工具栏与属性绑定、导航联动、浮动工具栏、截图与笔记操作协调 |
| `settings/` | 独立工具预设、统一外观更新、设置应用与取消 |
| `document/` | 会话身份、数据与待保存修改、附件写入及生命周期 |
| `library/`、`storage/` | 书库管理、永久删除恢复记录、原子写入、格式保护 |

建议将 `PdfView` 中新增的选择状态与几何操作适度拆分，避免继续集中堆叠全部 UI、数据和交互逻辑，但不要求本轮全面重写 `PdfView` 或 `DocumentSession`。复用已验证的统一页面坐标、渲染与保存机制；禁止额外建立与其不一致的坐标体系。

## 12. 验证与验收（F08）

### 12.1 构建及测试策略

- 使用当前仓库的 xmake 构建说明，验证正式应用及已有探针；优先在可获得的 Linux 与 Windows/MSVC 环境中编译运行。不能实际使用的环境应注明未验证，不得将静态判断标记为通过。

## 13. 本阶段范围控制
