# PANO Phase 1.1 — 界面优化与交互稳定化

> UI Refinement and Interaction Stabilization  
> 项目：`pano-reader`  
> 开发基线：`3618c16cbf2f156527b93ab71748ce5f3aaf35dd`（`phase 1: start dev`）  
> 文档日期：2026-11-27  
> 性质：Phase 1 收尾修复与界面重构，非全面阅读器功能扩展

## 1. 开发背景与目标

Phase 1 已建立正式工程、书库、书架、映射/拷贝导入、收藏、回收站、文档会话、多文档标签页、JSON 数据规范、配置分离与基础主题系统。用户实际测试表明主要功能可以使用，但界面组织和标注交互仍有较明显的 Demo 特征。

本阶段在正式工程 `src/` 内实施针对性优化，不再回到 `demo/` 开发。保留已经验证的 Qt PDF、页面 point 坐标、统一变换、异步渲染、矢量标注、局部荧光笔蒙版、独立 JSON 与 Markdown 笔记等技术路线。

本阶段目标：

- 书库与阅读工作区明确分离，形成统一、清晰、适合日常使用的界面。
- 建立全局字体、主题及图标管理机制，确保热切换与高 DPI 下的表现一致。
- 完善书库的文件夹式浏览、分类操作、封面/列表视图及详情展示。
- 建立阅读器左侧导航、中间阅读、右侧内容详情的三栏结构。
- 建立水平标注工具栏与上下文快速属性栏，实现独立工具预设。
- 修复文字高亮离散断裂，以及笔记编辑、自动保存、删除、设置初始化等基础问题。

完成本阶段后应能够以真实专业教材和论文进行日常阅读与标注。无需在本阶段完成所有长期规划功能。

## 3. R01/R02：数据安全与文档生命周期

### 3.1 笔记编辑对象绑定（R01）

当前 `src/app/ReaderWorkspace.cpp:348–379` 中，`beginNoteEdit()` 和 `commitNoteEdit()` 均通过 `currentAnnotation()` 获取对象。编辑期间切换标注时，提交目标可能发生变化；如果取消选中，提交还可能直接返回。该风险应优先修复。

要求：

1. 开始编辑时记录稳定的 `editingAnnotationId`（必要时同时记录书籍 ID），并加载该对象的笔记正文。提交、取消、插图、区域摘录等编辑操作均以该 ID 为目标，而不是临时选中的标注。
2. 选中对象变化前，提交当前编辑内容，然后切换到新对象。提交失败或目标已不存在时保留编辑缓冲并明确提示，不得写入其他标注。可通过统一选择协调入口实现；不得依赖多处信号的偶然执行顺序。
3. 关闭文档、切换标签、手动保存、移入回收站、切换书库之前，先提交当前笔记编辑缓冲，再进行持久化。
4. 文本编辑应纳入自动保存，默认停止输入 2 秒保存，持续编辑最长等待 30 秒。定时保存不应强制退出编辑模式、重置光标、选区或滚动位置。可区分提交缓冲与结束编辑两种操作。
5. 编辑内容变化需进入文档的修改状态；撤销/重做同样触发保存。避免每个字符都向文档撤销栈推入独立命令，可按编辑会话或短时间输入批次合并。文本编辑控件优先处理自身撤销与复制粘贴快捷键。
6. 取消编辑仅丢弃尚未提交的修改，不撤销已经自动保存的内容；在 UI 中明确这一语义，避免显示为可取消全部编辑。若采用实时模型更新，则提供明确的结束编辑而非虚假的取消按钮。
7. 删除正在编辑或附带笔记的标注前必须处理编辑缓冲。保留已有删除保护：允许取消、删除标注及笔记，或将有笔记的标注转为定位笔记（若当前尚不支持转换，至少提供取消及明确确认，不得无提示丢失笔记）。转换应作为一个可撤销操作。

### 3.2 保存状态分离与失败处理（R01/R12）

`DocumentSession::autosave()` 当前在 `!m_dirty` 时直接返回，而页码/缩放/旋转变化只调用保存调度；未提交笔记也未完全覆盖。建议区分以下状态（具体字段命名由实现决定）：

| 状态 | 对应持久化内容 |
|---|---|
| 标注及笔记修改 | `annotations.json` 与相关资源 |
| 笔记编辑缓冲修改 | 提交到对应标注后保存 |
| 阅读状态修改 | `state/reading.json` 等阅读状态文件 |

- 保持 2 秒延迟、30 秒最长等待的现有默认策略及可配置延迟。无变化不写入；单纯滚动不重写标注文件。
- 最长等待计时器应在每轮成功保存后正确重置；无待保存数据时停止计时。保存失败保留 dirty 状态，避免重复弹窗风暴，提供可见错误与手动重试入口。
- `Ctrl+S`、切换标签、关闭文档/程序、切换书库均处理相关数据。切换标签失败时不得静默丢弃修改；可保留原会话及错误状态，关闭和删除等不可逆操作必须阻止直至保存成功或用户明确选择放弃（删除不得因放弃保存而悄然继续）。
- 保存函数返回可靠结果；不能忽略阅读状态写入错误。避免 `saveNow()` 与 `flush()`、析构函数重复发出错误或重复写入。析构函数不承担需要用户决策的保存工作。
- 状态栏显示“已保存 / 未保存 / 正在保存 / 保存失败”。后台非当前标签的失败应在对应标签及切换/关闭时可发现。
- 保持 `QSaveFile` 原子写入和已有本地锁。检查标注文件也具有外部修改保护：加载时记录文件指纹/内容状态，写入前检测变化，冲突时不覆盖；仅依赖书库索引的检测是不够的。第一版不做冲突合并与跨设备写锁。

### 3.3 删除书籍与会话协调（R02）

当前 `LibraryView::moveToTrash()` / `deletePermanently()`（`LibraryView.cpp:582–625`）直接调用 `LibraryManager`，未统一处理打开的文档会话；`LibraryManager::deletePermanently()`（约 363–395 行）先递归删除目录，再保存书库及书架索引。

建立统一删除入口，由主窗口或轻量工作区协调逻辑处理会话，底层管理器仍负责书库状态及文件操作。菜单、右键、拖拽、回收站入口统一复用该流程。

- 软删除：确认后，若存在对应会话，先提交笔记、保存数据并关闭该会话；失败则中止。再改变 `deleted_at`，保留目录、原书架关联、收藏、历史和笔记。恢复时保留仍存在的原有分类。
- 回收站书籍不可继续打开为普通可编辑阅读会话；永久删除在业务层也必须验证书籍确实位于回收站，不能只依赖按钮可见性。
- 永久删除只处理程序管理的单本书目录及对应索引；绝不删除映射的外部 PDF。拷贝模式只清除内部副本。校验规范化路径、目录边界、符号链接/重解析点等，拒绝危险路径，不允许清除书库根目录或其他书籍数据。
- 多文件更新不能依赖单个 `QSaveFile` 获得事务语义。建议使用书库内受控的临时隔离目录及简单操作记录：先预检索引和文件状态，记录待删除书籍及关联数据，将目录移动到隔离区；更新索引、书架及阅读状态，失败时恢复或保留可恢复记录；只有元数据提交成功后才真正清理隔离目录。启动时识别中断的操作并提示恢复/继续。也允许等价的安全方案，不要求实现通用数据库或事务框架。
- 收藏、书架移动、删除等操作写入失败时应回滚内存中的变更，或重新加载一致的状态，不显示虚假的成功。
- 不在打开书籍时直接替换其 PDF 来源；需要重定位时先关闭相关会话并校验哈希。拷贝书籍仅在内部文件缺失等异常情况下提供同内容恢复入口，不能修改正常的源文件。

## 4. R03/R04/R13：全局外观与设置基础

### 4.1 字体与主题

现状：`MainWindow::applyThemeFromSettings()`（377–386 行）及 `SettingsDialog::applyFont()` 使用 `QApplication::setFont()`，同时 `ThemeManager` 应用全局 QSS。部分控件独立设置字体、固定高度或大小，用户实际测试仅菜单栏文字明显变化。具体传播原因需通过运行确认，不应仅凭静态检查断定某一个 API 是唯一原因。

统一由 `ThemeManager` 或单一外观协调入口应用字体、palette、QSS 与界面尺寸参数。避免由主窗口、设置窗口分别反复应用同一配置。应确保最终有效字号覆盖所有标准控件及已创建窗口，可采用动态生成 QSS 的统一字体规则或经过验证的等价方案；禁止在各面板中散布固定字号覆盖。

| 内容 | 建议尺寸规则 |
|---|---|
| 基础界面字体 | 默认 11 pt；保留用户已保存的字号 |
| 菜单、按钮、列表、标签、输入框 | 基础字号 |
| 面板标题 | 基础字号 + 1 pt，适当加粗 |
| 书籍详情标题 | 基础字号 + 3 pt |
| 辅助说明 | 基础字号或 -1 pt，保证可读 |
| 图标 | 通常 16–20 逻辑像素；主要工具 20–24，随字号适当调整 |
| 笔记正文 | 随基础字号合理显示；独立阅读字号后续可配置 |
| PDF 正文、标注线宽 | 不随 UI 字号或主题变化 |

上述数值是实施起点，不要求像素级复制。按钮、输入框、列表项、标签栏、标题和分隔线的尺寸应根据字体度量、sizeHint 与 DPI 自适应，避免文字裁切。原有固定尺寸（如列表项 84 px、某些侧栏最大宽度）需结合实际效果审查。

四种主题（现代浅色、经典、暖色、现代深色）继续保留。默认现代浅色。统一定义语义颜色：窗口、面板、阅读背景、边框、正文、辅助文字、强调、选中、悬停、禁用、错误。`PdfView::paintEvent()` 当前硬编码 `#eceef2`，应改为读取主题色；同样检查缩略图、封面占位、图标、笔记预览、页面阴影及选中框。

主题/字号热切换不得重建文档会话、重新加载 PDF 或清空标注、编辑缓冲、撤销历史。保持页内阅读锚点与面板状态；适应宽度模式可以重新计算比例，但内容定位应保持。PDF 纸面与标注实际颜色不随主题改变。

### 4.2 Lucide 图标系统（R04）

沿用 REST GUI 使用 Lucide 的经验，但 PANO 独立管理自己的资源，不依赖 REST 仓库或其构建环境。

- 上游：https://github.com/lucide-icons/lucide ，许可见上游 `LICENSE`；保留 ISC 与 Feather MIT 等适用的完整声明，记录实际采用版本/提交及来源。仅引入需要的 SVG，不引入完整图标运行框架。
- 建议 `resources/icons/`、`icons.qrc` 与统一 `IconManager`，通过语义 ID 获取 `QIcon`。可按主题对 SVG 的 `currentColor` 进行受控替换或着色，缓存按主题、尺寸、状态区分。处理高 DPI、禁用与选中状态。
- 主要工具使用图标加简短文字，紧凑区域可图标-only，但应有 tooltip、可访问名称及快捷键提示。避免使用 Unicode 字符冒充功能图标或混用多种图标风格。
- 图标示例：`library`、`folder`、`folder-plus`、`star`、`trash-2`、`file-plus`、`book-open`、`list-tree`、`images`、`mouse-pointer-2`、`hand`、`text-cursor`、`highlighter`、`underline`、`strikethrough`、`minus`、`square`、`circle`、`pencil`、`pen-line`、`eraser`、`sticky-note`、`scan`、`undo-2`、`redo-2`、`save`、`zoom-in`、`zoom-out`、`rotate-cw`、`settings`。开发时核对上游实际名称，文字高亮和自由荧光笔应有可区分的图标，必要时采用符合许可的轻量派生 SVG。
- 同一个 `QAction` 在菜单、工具栏和快捷键中共享语义与启用/选中状态，主题切换后刷新其图标，不重复绑定不同业务逻辑。

### 4.3 设置窗口（R13）

保留独立设置窗口及分类标签页。界面/数据与存储/阅读/标注/快捷键；仅展示当前真正支持的设置项，不提供无效控件。

`SettingsDialog::loadValues()`（235–264 行）在已连接实时更新信号后填充控件，存在初始化时写入不完整配置的风险。应使用初始化保护或 `QSignalBlocker`，完整加载后再允许用户编辑。

设置语义：打开窗口不改变实际配置；主题、字号允许即时预览；“应用”提交并保存当前草稿，同时更新取消的回退基线；“确定”执行应用并关闭；“取消”或关闭窗口撤销自上次应用以来的预览，不撤销之前已明确应用的设置。保存失败不能假定成功。其他设置以明确提交为准。

数据与存储页提供当前书库路径、打开目录、默认导入方式（映射/拷贝）；书库切换必须走安全切换流程，不直接修改路径字符串。本机配置中持久化默认导入方式，导入对话框允许本次覆盖。自动保存延迟及恢复打开标签等沿用既有设置。标注页使用按工具的预设管理或恢复默认值，不再将一个公共样式广播到所有会话。语言切换、自定义快捷键等未实现能力本阶段不强行增加。

### 5.2 工作区切换与工具栏实现

当前 `MainWindow::buildToolBar()`（319–368 行）将库操作及阅读操作混入全局工具栏，同时在左侧添加标注工具栏；`updateToolBarState()` 只更新启用状态。应删除该混合结构。

- 菜单栏和标签栏始终存在。书库操作在菜单、右键、局部标题区域和空状态中提供；书库不再显示独立的全宽管理工具栏。
- 阅读工具栏位于阅读工作区内部，只有当前标签为阅读工作区时才显示。可采用 `ReaderWorkspace` 内部工具栏，或共享但按上下文显示、绑定的工具栏；不得在书库中留下禁用工具、空白条或左侧工具占位。
- 页码、翻页、缩放、适宽、适页、旋转集中在底部阅读控制区域，保存状态与提示在同一区域或统一状态栏。避免两条重复状态栏。缓存大小等调试信息移至诊断入口。
- 页码输入使用 1-based 显示，底层仍为 0-based；输入完成时定位，不因编辑中间数字反复跳转。显示总页数，缩放支持预设值与自定义值。
- 每次切换标签时从目标会话主动同步当前工具、选中对象、属性、页码、缩放、旋转、撤销/重做可用性、保存状态；避免只依赖 `toolChanged` 等变化信号。
- 快捷键作用域正确：阅读器编辑命令仅针对活动会话，笔记正文输入时优先文本编辑器操作，书库删除不触发标注删除。工具栏刷新通过信号屏蔽避免反向修改文档。

## 6. R06：书库界面与管理操作

### 6.1 三栏布局

左侧导航、中间内容、右侧详情采用可调整的分隔布局。以 1440×900 逻辑窗口为参考，左栏约 220–260 px，右栏约 300–360 px，中间占据剩余空间。避免当前右栏与中间同等伸缩导致详情占据过多宽度。两侧可隐藏并恢复，尺寸和可见状态保存在本机配置中。窄窗口优先保障中间区域；右栏内容可滚动，避免按钮和文本溢出。

左侧仅展示书库视图与书架层级，不展开全部书籍。顶部提供新建书架图标及必要的局部操作。收藏、回收站使用不同图标；回收站位于底部或独立分组。普通书架右键提供新建子书架、重命名、移动、删除。

### 6.2 文件夹式浏览与视图

当前 `LibraryView::refreshBooks()`（314–387 行）递归汇总子书架中的书籍，只构建一种带封面的列表项。本阶段应实现以下浏览语义：

| 视图 | 中间区域展示内容 |
|---|---|
| 全部书籍 | 所有未删除书籍，不重复显示同一 ID |
| 普通书架 | 直属子书架（文件夹）及直接归属书籍 |
| 收藏 | 已收藏且未删除书籍 |
| 回收站 | 已软删除书籍 |

普通书架不默认递归汇总所有后代书籍。递归浏览可留作后续可选项。中间上方提供可点击的面包屑路径、搜索、排序与封面/列表视图切换；这属于局部浏览控制，不是全局管理工具栏。

封面视图使用真实第一页封面、统一宽度及合适长宽比，标题最多两行、完整标题通过 tooltip 查看；缺失封面显示一致的占位。子书架使用文件夹图标及名称，排在书籍之前。列表视图提供标题、作者、最近阅读/导入时间、文件大小、收藏等可用列。共享数据模型或统一数据源，切换视图不清除当前分类与选中对象。

排序优先提供书名、作者、导入时间、最近阅读时间及升降序，可保留收藏优先；阅读位置和文件大小如数据可用也可加入。搜索默认在当前视图范围内匹配书名、作者和直属子书架名称，空结果有提示；在全部书籍中搜索全库。避免每次搜索重新读取全部 PDF 或生成封面。

### 6.3 分类、拖拽与右键操作

底层继续支持一本书属于多个书架，书架本身为单父级树，不允许环。当前书库拖入主要识别外部 PDF URL，须补充内部拖拽。内部拖拽传递稳定 ID（及来源书架 ID），而不是把书籍当作实际文件移动。

| 源/目标 | 操作 |
|---|---|
| 外部 PDF → 书库/普通书架 | 导入，并在普通书架目标中建立关联 |
| 书籍 → 普通书架 | 从来源书架移除并加入目标；其他分类保持 |
| 书籍 + Ctrl → 普通书架 | 保留原归属，增加目标关联 |
| 全部书籍/收藏中的书籍 → 普通书架 | 增加目标关联，不取消收藏 |
| 正常书籍 → 收藏 | 设置收藏属性 |
| 正常书籍 → 回收站 | 走统一软删除流程及确认 |
| 书架 → 普通书架或根级 | 修改父级；拒绝自身及后代目标 |
| 回收站书籍 | 先通过恢复操作回到正常状态，不混用普通拖拽 |

同一目标重复添加不产生重复记录。拖拽到无效目标显示拒绝状态，不能悄然执行其他操作。多文件导入保留原有能力，若内部多选暂未实现可先支持单对象拖拽，不影响后续扩展。

右键菜单：

- 书籍：阅读、收藏/取消收藏、编辑信息（至少标题及作者）、移动到书架、添加到其他书架、从当前书架移除、打开文件位置、移入回收站。
- 书架：新建子书架、重命名、移动、删除。删除书架绝不删除书籍。当前实现采用删除中间书架并提升其直属子书架；本阶段建议保留此非破坏性行为，但必须在确认框中说明，并更新规范，避免与早期“删除整个分类子树”表述混淆。
- 空白处：导入 PDF、新建书架（当前普通书架或根级）、视图/排序。空书库提供显著导入入口，不要求用户必须发现右键菜单。
- 回收站：恢复、永久删除；清空回收站若实现必须逐项遵循 R02，明确确认。

### 6.4 右侧书籍详情面板

按以下顺序组织，不将全部元数据作为一段连续文本：

1. 封面及书名（可换行）、作者；页数、文件大小等摘要，收藏状态与继续阅读操作。
2. 阅读信息：上次阅读页码/总页数（可用时展示相对位置，不称为完成率）、最近阅读时间、标注数量、笔记数量。
3. 书籍信息：导入日期、存储方式、源文件状态、所属书架，提供编辑书籍信息及打开文件位置操作。
4. 高级信息：完整文件路径、书籍 ID、SHA-256 等放入可折叠区域或属性对话框，允许复制。映射源文件缺失时突出“重新定位”；正常拷贝书籍不常驻“更换源文件”。

没有选中对象时显示简洁提示；选中书架时显示书架名称、直接包含的书籍及子书架数量和相关操作。回收站视图不显示继续阅读，改为恢复与永久删除。不要用模拟数据填充未取得的页数、统计或历史。仅切换选择不得加载大型 PDF 获取详情；优先使用已持久化的元信息及现有状态。

## 7. R07/R08：阅读器三栏与导航

### 7.1 左栏导航

将当前 `ReaderWorkspace::buildUi()`（99–129 行）左侧“标注与笔记 / 属性”替换为“目录 / 页面 / 标注”三个标签。左栏只负责导航和筛选，不承担主要属性编辑。左右栏均可拖动宽度、独立隐藏和恢复，默认约 240/320 px，中心阅读区优先伸缩。面板布局为本机配置，不写入标注数据。

| 标签 | 实现要求 |
|---|---|
| 目录 | 使用 `QPdfBookmarkModel` 或 Qt PDF 等价接口，保留原生层级，支持展开/折叠；点击定位到目标页及可用的页内位置。无目录显示明确空状态，不自行推断章节。 |
| 页面 | 按物理页序列列出真实缩略图和 1-based 页码，当前页高亮；点击跳转，阅读滚动时同步当前页。 |
| 标注 | 显示类型图标、颜色、标题/原文摘要、页码；点击精准定位并同步右栏，支持类型/仅有笔记筛选，可按创建顺序或页码排序；默认创建顺序，筛选排序不得修改 JSON 中的存储顺序。 |

目录定位应复用 `goToPosition()` / `revealPageRegion()`；如果 Qt PDF 未提供可靠的页内目的坐标才回退页跳转，处理无效目标。此处读取 PDF 原生目录仅用于导航，不将书签标题或印刷页码作为标注持久化标识。页码仍以物理页面索引为准。

缩略图采用按需渲染：打开 864 页等长文档时，只请求可见及少量相邻缩略图，滚动/切换时优先当前需求。独立低分辨率缓存或明确的缓存配额，避免挤占阅读页面缓存；不阻塞主线程批量渲染。关闭会话或切换文档时拒绝过期回调。缩略图方向与当前视图旋转一致；本阶段不要求绘制每个缩略图上的标注。

### 7.2 中间阅读区

保留已验证的 `PdfView`、`PageLayout`、Qt PDF 与 point 坐标转换。页面、标注、选择框、命中检测、导航均使用统一变换，不能因面板重排再次引入偏移。PDF 视图旋转只改变显示，不变形、不改源 PDF，也不改标注坐标。

改造布局时检查适宽/适页是否为持续模式：侧栏显示、窗口缩放、字体改变等引起视口变化时，按当前模式更新缩放并保持页内锚点；固定倍率则保持倍率及内容定位。鼠标滚轮缩放和底部控制仍保持原有能力。新增拖动（手形）基础工具可利用现有滚动条实现，不应与选择/移动标注混淆；不要求实现复杂阅读布局。

### 7.3 右栏：笔记与详情

默认提供两个标签：

- 笔记：选中标注后展示标注类型及页码、可用的原文摘录、笔记标题与 Markdown 正文、图片、编辑入口。没有笔记时提供添加入口；未选中时提示选择标注或放置笔记定位点。编辑过程遵守 R01，允许保存后继续编辑，切换对象不串写。保留已有插图、区域截图及公式显示基线。
- 详情：仅针对选中标注展示类型、页码、创建/修改时间、必要几何信息和完整可编辑样式。高频属性在上方快速栏修改；右栏提供精细调整与详情，两个入口共享同一状态，不重复维护模型。原始 ID/坐标等技术信息可放在高级区域。

本阶段不新增完整笔记树，不替换 Markdown 或公式引擎。已有笔记及资源不能因界面重构退化或丢失。

## 8. R09/R10：工具栏与独立预设

### 8.1 一级工具栏

按以下顺序组织，从左到右，每组之间使用分隔线。主要操作均使用统一图标与简短文字：

| 分组 | 工具 |
|---|---|
| 文档编辑 | 保存、撤销、重做 |
| 基础操作 | 选择/移动标注、手形拖动页面、文本选择 |
| 文字标注 | 文字高亮、下划线、删除线 |
| 图形标注 | 直线、矩形、椭圆 |
| 画笔 | 铅笔、荧光笔、橡皮擦 |
| 笔记 | 定位笔记、区域摘录（如需笔记目标则明确提示） |

工具选择互斥，当前工具具有清楚的选中状态。创建标注后默认保持工具，Esc 取消正在绘制的临时对象；再次 Esc 或退出编辑返回选择工具。保持已有 Shift 直线及水平/竖直吸附。图形和路径拖动期间必须正确显示预览，鼠标释放才提交一次撤销命令。

### 8.2 二级上下文属性栏

位于一级工具栏正下方，不占用左侧导航。参考用户提供的图3：通过颜色下拉、线宽预设、填充、透明度等紧凑控件直接调整，不需要打开左侧属性页或额外点击“应用样式”。

```text
绘制矩形： [矩形] | [描边颜色 ▼] [1.5 pt ▼] [填充：无 ▼] [100% ▼] [普通 ▼] | [退出编辑]
绘制荧光笔：[荧光笔] | [颜色 ▼] [12 pt ▼] [80% ▼] [正片叠底 ▼] | [退出编辑]
文字高亮： [文字高亮] | [颜色 ▼] [70% ▼] [正片叠底 ▼] | [退出编辑]
选择对象： [选中：矩形] | [描边] [线宽] [填充] [不透明度] [混合] | [删除]
```

| 当前工具 | 显示属性 |
|---|---|
| 文字高亮 | 颜色、不透明度、混合模式；不显示无意义的线宽 |
| 下划线/删除线 | 颜色、线宽、不透明度 |
| 直线/铅笔 | 颜色、线宽、不透明度、混合模式 |
| 矩形/椭圆 | 描边颜色、线宽、填充颜色（含无填充）、不透明度、混合模式 |
| 荧光笔 | 颜色、笔宽、不透明度、混合模式 |
| 橡皮擦 | 当前支持的对象擦除方式；可用时显示擦除范围，不能放置无效尺寸控件 |
| 定位笔记 | 定位点颜色及适用属性 |
| 选择 | 按已选对象类型显示对应属性，无选中对象时隐藏或显示简洁提示 |
| 手形拖动/普通文本选择 | 不显示无关属性 |

颜色提供常用色板及自定义颜色对话框，支持无填充；不透明度统一使用可理解的百分比。避免 QColor alpha 与 opacity 控件无意重复乘算；如保留独立 alpha，必须明确其语义。宽度单位 pt，显示单位与持久化一致。对于对象属性修改，拖动滑块可以实时预览，但一次完整拖动合并成一次撤销命令。

必须区分两种状态：绘制工具下调整的是该工具的新建预设，即使之前存在选中标注，也不能修改旧对象；选择工具下调整的是当前对象并进入撤销栈，不改变任何工具预设。工具切换后主动更新属性栏，刷新控件时不能触发反向写入。

橡皮擦本阶段至少维持现有对象级点击删除并落实笔记保护；建议在不扩大范围的前提下支持连续拖动对象擦除并合并撤销。若连续擦除暂缓，保持明确的点击语义，不添加无效模式切换。自由笔画的像素级局部擦除不在本阶段。

### 8.3 独立工具预设与持久化

当前 `PdfView::setDefaultStyle()` 设置 `m_styleUserModified = true` 后，`applyToolPreset()` 不再应用任何工具默认值；`ReaderWorkspace::applyStyle()` 同时修改选中对象和默认样式；设置窗口还会广播公共样式。必须移除这类公共样式覆盖逻辑。

建立按稳定工具 ID 索引的 `ToolPresets`（可归入 SettingsManager 或独立轻量类），保存本机 `tools.json`。预设在应用范围共享，各会话保留自己当前选择的工具及选中对象。切换工具/文档时读取对应预设，新建标注时复制完整样式快照；旧标注不受预设、主题或重启影响。设置修改、工具栏修改使用同一预设数据源；已有标注的属性不写回预设。支持按工具恢复出厂默认值。

建议出厂默认值（可在实际视觉检查后适度调整，更新文档）：

| 工具 ID | 颜色 | 宽度 | 不透明度 | 混合 |
|---|---|---:|---:|---|
| `text_highlight` | `#FFE066` | 不适用 | 70% | multiply |
| `underline` | `#477EB8` | 1 pt | 100% | normal |
| `strikeout` | `#D94F4F` | 1 pt | 100% | normal |
| `line` | `#D94F4F` | 1.5 pt | 100% | normal |
| `rectangle` | `#D94F4F` | 1.5 pt | 100% | normal |
| `ellipse` | `#D94F4F` | 1.5 pt | 100% | normal |
| `pencil` | `#344054` | 1.5 pt | 100% | normal |
| `highlighter` | `#45B9E6` | 12 pt | 80% | multiply |
| `note_point` | `#F59E0B` | 不适用 | 100% | normal |

矩形/椭圆默认无填充。上述 ID 属于工具配置，可与标注类型枚举独立；实现应使用稳定映射。荧光笔与铅笔使用相同的自由路径数据结构，但前者必须默认粗线、正片叠底，并保持单笔画内部一次合成。允许用户修改，不在创建对象时再次强制限制属性。对于单击形成的笔画也应保持实际绘制区域与命中检测一致。

`tools.json` 建议格式：

```json
{
  "format": "pano-tool-presets",
  "schema_version": 1,
  "presets": {
    "pencil": {
      "stroke_color": "#344054",
      "stroke_width_pt": 1.5,
      "opacity": 1.0,
      "blend_mode": "normal"
    },
    "highlighter": {
      "stroke_color": "#45B9E6",
      "stroke_width_pt": 12.0,
      "opacity": 0.8,
      "blend_mode": "multiply"
    }
  }
}
```

示例仅展示两个工具；完整字段名、颜色格式应与正式 `AnnotationStyle` 数据约定保持一致。缺失工具采用出厂值；配置损坏或未知版本提示并保留原文件，不能静默覆盖。不得把本机工具配置写到书库目录中。

## 9. R11：文字标注几何整理

### 9.1 问题与设计原则

`PdfView::createTextAnnotation()`（1652–1671 行）直接保存 `selection.bounds()`，`AnnotationRenderer::polygonPath()` 与 `paint()`（23–29、250–266 行）逐多边形绘制高亮或线条。用户提供的英文论文截图出现词语/字符间断裂。Qt 返回边界的具体粒度随 PDF 内容而异，需用实际选区数据验证；不能假定始终按单字返回。

目标是将同一连续文本行的正常文字间隙连接起来，保留换行、分栏、段落和不连续选择的边界。**不得用整段选区的单个外接矩形替代原有多边形。**

### 9.2 建议算法

建立轻量 `TextSelectionGeometry` 模块，接收原始选区多边形及可用的文字索引/方向信息，生成用于显示和命中检测的连续行区段。

1. 在未施加用户视图旋转的标准 page-point 坐标中处理几何，过滤无效、非有限或退化区域。不要在屏幕像素空间判断同一文本行。
2. 根据多边形方向及在文本方向的投影识别行。常规水平文本可使用垂向重叠、中心位置及局部文字高度进行聚类；不要仅根据 y 坐标是否相等分组。对于倾斜、竖排、方向混杂或无法可靠判断的文本，保留原始边界作为保守回退。
3. 在每个候选行内按文本方向组织片段。使用局部字高/典型间距等相对量确定合理间隔阈值，结合选区顺序和可取得的索引信息，合并正常词间空隙。大间隙、栏间空白、不同文本块、未选择区段必须分开。阈值应有明确名称并通过样例验证，不硬编码依赖缩放的像素距离。
4. 为每个连续区段构建合适的行带；上下边界按局部行高和文字实际范围确定，兼顾上下标和不同字号。保留首尾的实际选择边界，不自动延伸到整行或整页。
5. 高亮使用每个连续行区段的填充；下划线/删除线按区段绘制连续线条。处理同一个标注内部区域重叠时避免重复叠加透明度，保持正片叠底与普通混合的现有语义。

不要求实现完整的 PDF 排版识别算法。优先使一般英文、中文水平文本及双栏论文正确，复杂公式、特殊排版不能可靠合并时宁可保留局部断裂，也不要覆盖无关区域。

### 9.3 数据兼容与统一使用

保持 `page_index`、原始文字索引、文字内容及原始几何多边形的持久化语义不变。合并几何为派生数据，按需计算，可对已有标注缓存；缓存应在几何变化时失效，而不依赖视图缩放。原则上不为本项修改升级 `annotations.json` 的协议版本，也不批量重写已有标注。

文字选择预览、已保存标注渲染、下划线/删除线、命中检测与定位区域共享同一套几何整理结果或一致的派生规则，避免视觉上已连续但中间仍无法选中的情况。已有标注重新打开后应自动获得改进的显示效果。若现有数据不足以可靠整理，保留原始几何。

可增加少量确定性几何检查：同一行的正常词间隔应合并；上下相邻行分开；同一高度的两个远离文本块分开；部分行选择保持边界。再以实际 PDF 视觉验证，不能只用合成矩形测试替代。

## 10. R12：会话状态、阅读锚点及职责收敛

当前 `DocumentSession::readingState()`（255–265 行）保存页码、倍率、旋转与缩放模式，恢复时调用 `goToPage()`，不能恢复具体页内阅读位置。

- 增加可选页内锚点（标准页面 point 坐标），例如当前视口中心或上方固定参考位置对应的页内点。选定一种稳定的参考位置，记录页面 ID/索引及锚点；恢复时保证同一参考位置附近的原文可见。若参考点落在页间空白，选择最近或主要可见页面并约束到页面内。
- 同页滚动也应触发阅读状态的延迟保存，而不仅监听页码变化。使用合并调度避免每次滚动事件写盘。
- 恢复顺序：加载文档、建立页面布局、应用旋转、设置缩放模式/倍率，再定位页内锚点；视口未就绪时适当延迟至布局完成。若旧数据没有锚点，则按原页码恢复。
- 兼容 Phase 1 真实书库。不改变现有字段含义；页内锚点如果作为向后兼容的可选字段加入，须验证旧格式读取行为并更新规范。若引入不兼容变化则明确升级 schema、备份与迁移；不得静默丢弃旧字段。
- 多文档会话各自保持标注模型、撤销历史、当前选中对象、工具及阅读状态。工具预设属于本机共享设置，不属于书籍文件。关闭会话释放页面及缩略图资源、取消或忽略过期异步结果。
- `PdfView` 当前仍持有文档、标注模型和撤销栈，`DocumentSession` 间接访问这些对象。此轮不要求全面迁移其所有权，但新增加的保存状态、笔记编辑协调、工具预设与导航 UI 不应全部堆入 `PdfView`。适当提取轻量组件，避免为后续功能增加不必要的耦合。若确实调整所有权，明确对象生命周期、Qt 父子关系与信号解绑。
- 书库详情的统计、阅读位置等在会话保存和切换书库标签时更新；避免后台信号触发整库重复刷新。全局界面配置（布局、字号、主题、视图模式）与书籍阅读状态保持分离。

## 11. 数据规范及兼容性要求

Phase 1 已有实际书籍、标注与笔记数据，本阶段应保持正式数据可读，不允许采取删除现有书库重新初始化的开发方式。

| 数据 | 处理 |
|---|---|
| `library.json` / `shelves.json` / `document.json` | 保持现有 schema 与 ID 关联，除非有明确迁移需要 |
| `annotations.json` | 原始几何、样式、Markdown、资源引用保持兼容；不要重算已有标注样式 |
| `note_tree` | 本轮不实现笔记树，但写入时不得静默清空已有未知组织数据；不支持的结构应保留或拒绝覆盖 |
| `state/reading.json` | 可增加可选页内锚点，明确坐标单位及回退行为 |
| 本机配置 | 增加工具预设、默认导入方式、视图及面板状态等必要字段；配置默认值与实际生效行为一致 |
| 原 PDF | 映射和拷贝均保持只读；删除仅按受控书籍生命周期进行 |

修改协议或新增配置文件时同步更新 `docs/specification/phase1-data-formats.md`（或相应正式规范）。保持 UTF-8、可读 JSON、稳定 ID 及相对资源路径。无法识别的高版本或不支持结构不得重新序列化为不完整数据。

## 13. 本阶段暂缓事项

- 成熟 Markdown/公式渲染库的最终集成（MD4C、JKQTMathText 等仍待专门验证），不继续大规模扩展自研解析器。
- 完整笔记树、多对多笔记关联及跨书籍笔记。
- 单页/双页等完整布局体系、全文搜索、高级渲染调度及 GPU 渲染重构。
- 大量新增标注类型（文本框、图片、超链接等）及复杂文字范围编辑；选中文字浮动工具栏可留待标注系统阶段，当前工具栏必须可用。
- OCR、带标注 PDF 导出、便携书库导出、跨设备同步和冲突合并。
- 完整国际化、安装包与正式发布、用户自定义主题编辑器。

## 14. 交付要求与阶段退出条件

1. 正式工程完成 R01–R14，保留 Demo 独立性及原有基础功能。关键数据安全问题不可作为普通视觉问题遗留。

4. Git 提交信息简洁明确，使用 `fix:`、`feat:`、`refactor:`、`docs:` 等常规前缀，不提交构建缓存、用户书库或私有测试资料。
