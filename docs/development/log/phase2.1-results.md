## 2. 实现结果

### R01 全屏

- `MainWindow` 统一管理全屏状态，连接 `ReaderWorkspace::fullscreenRequested`；F11 使用
  `WindowShortcut`，菜单隐藏后仍可用；菜单动作与按钮共享 checked 状态。
- 全屏保存窗口几何、面板、工具栏和阅读锚点；退出后恢复界面，但不强制把阅读位置拉回
  全屏前，保留用户全屏期间读到的新位置。
- 阅读器视口右上角增加常驻“退出全屏”按钮，已在离屏探针中真实点击验证。
- Esc 顺序由 `ReaderWorkspace::closeTransientUi()` 与 `MainWindow` 事件过滤共同处理：
  先关闭搜索/浮动条/临时选择，再退出全屏。

### R02 橡皮

- 自绘圆形橡皮光标，半径与擦除判定一致，绘制在 viewport 上，不依赖 PDF 重绘。
- 使用 `QPainterPathStroker` 构造采样点之间的胶囊形命中区域，而不是只判断采样点中心；
  空心矩形/椭圆内部不会误擦。
- 一次按住拖动只提交一个 `RemoveAnnotationsCommand`；擦除前即时隐藏命中的对象作为预览，
  释放时统一删除；无命中不产生撤销命令。
- 跨页拖动按实际可见页面分别采样，页面间隙不参与；同一对象按 ID 去重；带笔记对象跳过并
  合并提示；Esc、切换工具、切换文档、鼠标丢失会取消并恢复预览。
- 探针模拟连续拖动，验证一次操作删除两个对象、一次撤销全部恢复。

### R03 非连续翻页与滚轮

- `wheel_turns_page` 默认开启，但已显式保存为 `false` 的旧配置保持关闭。
- 非连续布局下先滚动页内内容，到边界后累积滚轮/触控板增量再翻到下一页/组；反向翻到
  上一页底部；使用 `PageLayout::spreadPages()`，双页、首页单独和末尾单页按真实组切换。
- 250 ms 冷却与方向重置避免触控板惯性一次跨多页；Ctrl 缩放、Shift 横向滚动保持原有优先级。
- 连续布局保持普通滚动。PageUp/PageDown 在非连续布局翻页，在连续布局按视口滚动；
  文本编辑器保留原生按键行为。
- 滚轮和页按钮翻页不写入导航历史。

### R04 页码控件

- 页码输入框为无按钮可编辑控件（`QLineEdit` + `QIntValidator`），界面 1-based，回车提交，显示总页数。
- 上一页/下一页独立按钮，首尾正确禁用；翻页遵循 R03 的组语义；页码输入可直达指定页。
- 历史后退/前进独立成组，不与翻页按钮混用。相关入口位于阅读器顶部工具栏。

### R05 导航历史

- `PdfView::navigateTo()` 在切换前发出 `aboutToNavigate(fromPage, fromPoint, target, reason)`；
  阅读器保存真实出发锚点，目标导航成功后再建立历史节点。
- 只有显式入口（页码、目录、缩略图、书签、搜索、标注定位）入栈；滚动、普通翻页、缩放、
  旋转、布局切换、恢复阅读状态、编辑不入栈。
- 后退/前进使用 `NavigationReason::History`，不会再次入栈；新跳转截断前进分支；
  重复位置与空操作去重；每会话上限 100，不持久化。

### R06 滚动范围与定位

- `navigateTo` 先设置目标页、完成布局/适合缩放，再 `updateScrollBars()`，最后按
  PageTop/Center/PageBottom/页内点定位，避免旧连续布局的滚动范围把目标页推走。
- 修复布局切换后页面空白：`applyFitZoom()` 在缩放值未变化时也必须刷新滚动范围。
- 旋转、窗口尺寸、侧栏伸缩、全屏恢复后重新计算适合缩放；固定缩放导航不会改变比例。

### U01 顶部工具栏

- 阅读器只保留顶部两级工具栏：主工具/导航栏 + 当前工具/对象属性栏；底部控制栏改为纯状态。
- 主工具栏按组排列：保存/撤销/重做/删除；历史后退/前进、上一页/页码/下一页；缩放；
  单页/双页与连续开关、首页单独、旋转；工具；搜索/书签/侧栏/全屏。
- 窄窗口可横向滚动；菜单保留完整入口；页码与缩放控件宽度可容纳大文档与较大字体。

### U02 布局控件

- 以“单页/双页 + 连续”的正交组合替代四选一下拉框，内部仍映射为四种 `PageLayoutMode`。
- 双页显示“首页单独”，单页隐藏但保留值；控件与实际布局双向同步，切换时保持阅读锚点。

### U03 左侧导航与缩略图

- 左栏标签改为 目录 / 页面 / 书签 / 查找；标注列表移到右栏。
- 左栏保持可拖拽、可隐藏，默认 240 px，最小 160 px；四个标签在默认宽度下全部可见。
- 缩略图约 120×158，随视口宽度自动换列；仅在页面标签可见时按当前页附近请求，缓存
  已生成/请求中的页面，旋转后重建；滚动到远处再按需请求，不一次性生成全部缩略图。

### U04 查找

- 全文搜索整体移入左栏“查找”标签，顶部不再占用第二行搜索空间。
- `Ctrl+F` 展开左栏并聚焦、全选文本；重复按下只重新聚焦，不关闭也不清空；
  关闭按钮/Esc 清空查询、临时高亮并返回之前的导航标签。
- 250 ms 防抖；显示“搜索中 / 已找到 N 处 / 无结果”；扫描件给出无可搜索文本提示。
- 结果包含页码、命中关键词和上下文；当前结果的所有矩形单独高亮；支持 Enter/F3 下一个、
  Shift+Enter/Shift+F3 上一个；结果超过 4000 时显示 `shown/total`。
- 临时高亮不进入标注模型、撤销栈、保存或区域截图。

### U05 右侧标注栏

- 右栏改为 标注 / 笔记 / 详情，默认“标注”；标注列表、筛选、排序、预览和操作均在此。
- 类型筛选 + 仅有笔记；排序支持创建顺序、按页、最近修改；排序只影响显示，不修改 JSON
  叠放顺序。
- 列表项显示类型、页码、文字摘录或笔记标题；下方预览显示类型/页码/摘录/笔记，提供
  定位、笔记、删除。选中项被筛选隐藏时给出明确提示。
- 列表选择与 PDF 选择按标注 ID 同步；主动定位才触发跳转；阅读滚动不夺走列表选择。

### U06 面板与全屏

- 顶部提供左右面板开关，正常模式恢复宽度与可见性；全屏默认只保留画布和右上角退出按钮，
  隐藏菜单、标签栏、搜索、浮动条和侧栏；退出后恢复原状态。
- 不强制保留底部工具栏；阅读状态在右侧状态区显示。

### P01 大 PDF 打开计时

新增 `tools/open_timing_probe.cpp` 与 `pano-open-timing` 目标，通过 `PANO_OPEN_TIMING`
记录 GUI 打开路径：

| 环节 | `Primer C++(第5版).pdf`（199 MB / 864 页） | 示例 PDF（3 页） |
|---|---:|---:|
| 导入/建库 | 1121 ms | 27 ms |
| 源文件 SHA-256 校验 | 1015 ms | 0 ms |
| Qt PDF 打开/页数 | 1149 ms | 2 ms |
| 会话数据加载 | 1149 ms | 2 ms |
| 会话完成 | 2191 ms | 28 ms |
| 窗口挂载 | 2208 ms | 44 ms |
| 打开 + 首屏缓存 | 2230 ms | 68 ms |

结论：大文件打开的主要阻塞是每次打开重新计算整个源文件 SHA-256（约 1.0 s），Qt PDF
打开本身约 0.14 s；页面尺寸、标注、书签和首屏渲染不是主要来源。P02 的异步/增量校验
未实现，避免削弱内容身份与数据安全；本阶段记录证据，后续单独设计可取消的后台校验。

## 6. 已知限制

- P02 异步哈希未实现；大文件打开仍有约 1 s 的主线程 SHA-256。后续需可取消的后台校验，
  不能用文件大小/mtime 代替内容身份。
- 真实鼠标/触控板的手势阈值、全屏 F11/Esc、橡皮光标跟随、窄窗口溢出仍需人工验收。
- 右栏标注筛选与 PDF 选择的逐项双向同步、双栏文字选择、扫描件搜索未自动化。
- 未在 Windows 与高 DPI 环境构建；未在持久书库 `~/Documents/pano` 做完整人工回归。
- 导航历史、搜索和临时选择按设计不持久化；只保存面板尺寸、阅读布局与锚点。

## 7. 结论

Phase 2.1 的阅读器交互修复与界面重排已完成：全屏有明确退出路径，橡皮、滚轮翻页、页码、
历史和滚动范围按文档语义实现；阅读器改为顶部工具栏、左侧文档导航、右侧标注/笔记/详情、
底部状态；查找和缩略图进入侧栏并按需工作。自动化探针全部通过，P01 已定位到源文件哈希，
P02 以证据延期。剩余主要为真实桌面交互与跨平台人工验收。
