## 实现摘要

### R01 标准数学常量

`TextSelectionGeometry.cpp` 与 `PdfView.cpp` 改用 `std::numbers::pi`，不再依赖
`M_PI`。

### R02 点集边界与退化几何

新增 `AnnotationGeometry`：

- `pathBounds` 按所有点的 min/max 计算，空点集才返回 null；水平/竖直路径宽或高为 0
  仍是有效边界。
- `mapPointsToBounds` 在源轴退化为 0 时映射到目标中心，避免除零。
- 直线、自由路径的 `setBounds` 不再因初始宽高为 0 而拒绝；单点/双点路径可缩放。
- 标注定位区域不再回退到旧 `p1`，避免自由路径跳到页面原点。

### R03 选择不自动定位

`ReaderWorkspace::onSelectionChanged` 不再调用 `revealAnnotation`。只有左侧标注列表、
目录/缩略图、明确导航才执行精确定位。

### R04 永久删除隔离与恢复

永久删除只接受回收站中的书，并把书籍目录移入书库根目录 `.pending-delete/` 隔离区，
写入阶段标记；索引、书架、阅读状态、历史全部写成功后才清理隔离目录。任一步失败会
回滚并返回错误。打开书库时扫描标记：未提交的删除恢复目录，已提交的删除清理隔离内容。
真正删除前不会先删除源 PDF；映射模式源文件不在书库内，永远不会被删除。

### R05 字体与主题

`ThemeManager::applyAppearance` 统一设置应用字体、palette、QSS，并按新旧基线比例调整
现有控件字号；主题切换保留阅读页面锚点、选择和撤销历史。`MarkdownPreview` 标题字号
按当前界面字号相对计算，代码/表格颜色跟随 palette。

### R06 文字选区连续性

新文字标注持久化 PDF 引擎返回的**原始多边形**，渲染、命中、定位时按行合并：

- 先按字形框垂直重叠/中心线分行，容忍上标和小字号；
- 行内按局部字高和相邻字距估计词间距，不合并栏间/段间大空隙；
- 倾斜/竖直文本安全回退到原始多边形；
- 旧合并几何仍可读取，显示时重新归一化，不批量改写 JSON。

### R07/F01/F02/F03 样式与几何编辑

- `AnnotationStyle` 增加 `line_style` 与 `stroke_enabled`；旧文件缺省实线、描边开启。
- 阅读器属性栏增加线型与描边开关；线宽、透明度改动立即生效，属性栏修改按目标快照
  写入：选择对象时修改对象并进入撤销栈，绘制工具时修改工具预设。
- 直线/矩形/椭圆支持 Shift 45° 吸附、正方形/正圆；直线与双点路径支持端点编辑，
  其他路径保留八点缩放，角点 Shift 保持比例。
- 设置窗口按工具分别暂存颜色、线宽、线型、描边、填充、透明度和混合模式，应用/确定
  才写入 `tools.json`。

### R08/F04–F07 选择与浮动操作

- 选择工具单击文字进入文本选择，拖动空白框选区域；Ctrl 强制框选，Alt 强制文字；
  显式框选不受对象命中影响。
- 文本浮动条：高亮、下划线、删除线、复制、笔记；区域浮动条：复制图片、保存图片、
  矩形、区域高亮、笔记。
- 区域截图由页面渲染与已有标注合成，裁剪到页面 pt 区域，不包含浮动条/选区虚线；
  笔记操作把截图保存到书籍 `assets/` 并插入 Markdown。
- 阅读器只保留两级水平工具栏；移除重复的文字选择工具入口，区域选择使用独立工具。
- 浮动条随缩放/旋转/滚动重新定位，选区不可见或工具不匹配时隐藏。
