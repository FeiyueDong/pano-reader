## 已知限制与后续建议

- Windows、高 DPI、超大 PDF、扫描 PDF、双栏跨栏选区仍需真实桌面复核。
- 橡皮仍是点击删除，未实现连续擦除。
- 书架换父级、永久删除中途失败的恢复路径尚未补齐自动化覆盖。
- 圆角/专业字体/更细的图标对比度属于视觉打磨项。
- 文本合并阈值基于本地行高，遇到上下标混排或极端排版时应优先保留原始多边形；当前
  实现已对非轴对齐/旋转文字回退到原始多边形。

Phase 1.1 的界面骨架、图标工具条、三栏阅读器、笔记绑定/自动保存、独立工具预设、文字
几何合并、外部修改保护和数据格式文档已完成；数据、坐标、文字几何、主题和 UI 闭环
探针全部通过。剩余项集中在真实桌面交互验收、少数生命周期边界和视觉打磨，不应把
本记录中的“部分完成”当作已通过人工验收。
